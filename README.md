# Handwritten Medical Prescription Classification using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to classify handwritten medical prescription images into two classes. The project is based on the **Handwritten Medical Prescription Collection** dataset obtained from Kaggle.

The images are preprocessed using OpenCV and classified using a **Support Vector Machine (SVM)** algorithm.

The model performance is evaluated using:

- Accuracy
- Precision
- Classification Report
- Confusion Matrix
- ROC Curve
- ROC-AUC Score

---

## 📂 Dataset

**Dataset Name:** Handwritten Medical Prescription Collection

**Source:** Kaggle

The dataset contains handwritten medical prescription images with corresponding class labels.

## ⚙️ Methodology

The project follows these steps:

1. Load the labeled prescription images.
2. Convert images from color to grayscale.
3. Resize images to **64 × 64 pixels**.
4. Normalize pixel values between 0 and 1.
5. Flatten each image into a feature vector.
6. Split the dataset into training and testing sets.
7. Train an **SVM classifier**.
8. Predict the classes of test images.
9. Calculate model performance.
10. Generate the confusion matrix and ROC curve.

---

## 🤖 Machine Learning Algorithm

### Support Vector Machine (SVM)

Support Vector Machine is a supervised machine learning algorithm used for classification.

In this project, SVM is used to classify the handwritten prescription images into two classes.

The model uses:

- Kernel: RBF
- C: 10
- Class Weight: Balanced

---

## 📊 Feature Extraction

Each image is resized to:

**64 × 64 pixels**

Therefore, each image produces:

**64 × 64 = 4096 features**

The resulting feature matrix contains:

**129 × 4096 features**
